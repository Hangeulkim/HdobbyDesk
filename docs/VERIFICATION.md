- Python 검사 27개 통과.
- 사설 네트워크 정책 검사 3개 통과.
- Flutter 입력 패키지 검사 59개 통과. 좁은 휴대폰 화면에서 권한 설명과 요청 버튼이 함께 표시되는 회귀 검사 포함. 2125 설치본에서도 권한 제목·설명·요청 버튼이 좁은 화면에 정상 표시됨을 확인.

- 임시 Android 호스트 시험 종료 후 화면 공유가 비활성화됐고 TLS 수신 포트가 열려 있지 않음을 확인.
