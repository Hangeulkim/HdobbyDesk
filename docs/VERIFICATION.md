소스와 로컬 검사:

- Python 검사 27개 통과.
- 사설 네트워크 정책 검사 3개 통과.
- Flutter 입력 패키지 검사 59개 통과. 좁은 휴대폰 화면에서 권한 설명과 요청 버튼이 함께 표시되는 회귀 검사 포함. 수정한 설치본 화면은 별도 확인 필요.
- 현재 소스로 직접 TLS 검사 24개 통과. 인증서 유지·손상·권한 검사, 인증서 불일치 거부, 암호화 루프백 송수신, 변조·재전송 거부, 시간 제한과 종료 경로 포함.
- 새 GitHub 체크아웃에서 Flutter 의존성 준비 후 Rust–Dart 연결 코드 생성 성공. 전체 앱 빌드·패키징 성공으로 간주하지 않음.
- 가상 Android 호스트에서 인증서 표시, 해당 인증서의 로컬 TLS 수신 검증, 화면 공유 활성화 확인. 연결 코드 복사·붙여넣기로 주소와 인증서 자동 입력 확인. 다른 기기의 최초 등록·접속 전체 흐름은 미완료.
- 임시 Android 호스트 시험 종료 후 화면 공유가 비활성화됐고 TLS 수신 포트가 열려 있지 않음을 확인.
- 고정된 원본 `hbb_common`에 패치를 적용한 13개 파일이 현재 수정본과 바이트 단위로 일치함을 확인.
- GitHub에 올린 소스를 새 디렉터리에 받아 서브모듈 초기화·패치 적용·재적용 확인을 실행. 13개 파일의 일치와 Python 검사 27개 통과를 다시 확인.
- 변경 소스의 비밀정보 검사 통과. 실제 운영 주소·기기 식별자·로컬 사용자 경로가 업로드 대상에 없는지 별도 확인.
